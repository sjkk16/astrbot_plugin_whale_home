## 安装

环境：**AstrBot >=4.29.3,<5，Python >=3.12**。

1. 推荐从 [v0.4.2 Release](https://github.com/sjkk16/astrbot_plugin_whale_home/releases/tag/v0.4.2) 下载完整安装 ZIP，然后在 AstrBot 插件管理中从本地文件安装 `astrbot_plugin_whale_home-v0.4.2.zip`，不要选择源码包。
2. 启用插件，打开可视化视图「鲸鱼娘的小家」。页面、脚本和图片已随包提供，不需要 Node.js。
3. 无需选择模型即可点击房间活动点、使用物品、赠送心意。
4. 需要聊天时，在小家设置中选择已经在 AstrBot 配置好的文本模型并保存。
5. 需要后台生活时，手动打开「开启自主生活」并保存。首次安装及旧版迁移后均默认暂停。

底部导航打开聊天、物品、日记和设置。桌面端面板浮在房间上方，不改变房间比例；手机端为底部抽屉，不强制横屏。关闭面板后可完整查看背景。

## 固定场景怎么玩

点击微光或打开「活动列表」，先选择位置，再点击确认操作：

| 位置 | 活动 | 角色站位 |
| --- | --- | --- |
| 书架 | 读一会儿书 | 书桌前 |
| 书桌 | 玩一会儿电脑 | 书桌前 |
| 窗边 | 一起看夜景 | 窗前 |
| 床边 | 在床边休息 | 床边 |

家具是背景的一部分，不可拖动、删除或重复叠加。角色沿前景通道在三个站位间移动。
默认使用正常人物比例，设置中可切换 Q 版。提供呼吸、移动和落地阴影；开启系统“减少动态效果”后取消动画和飘雪。
**正常比例角色已含阅读、掌机游戏和站立休息等专用差分；没有坐椅子或躺进被窝的动画。电脑活动不冒充掌机动作。** 场景一直为夜景，不含昼夜切换或三维镜头。

## 收纳与自定义物品

- 物品库全部免费，可添加到收纳后直接使用或赠送，不需要摆放。
- 固定家具活动永久可用，不消耗库存；使用库存食物和饮品会扣减对应实例的数量。
- 消耗品用完保留空实例，可以移除后重新补充。耐用品可反复使用。
- 自定义物品支持名称、描述、类别、预设用途和图片。家具类自定义物品是收纳纪念物，不改变背景家具。
- 删除自定义种类会同时移除对应实例，历史日记保持原样。移除单件物品需确认。
- 描述不会赋予物品运行代码、访问网络或其他工具的能力。
- 日记保存实际执行的动作；共同记忆由真实经历及手动偏好构成。删除记忆不会同时删除对应聊天或日记。

## 模型与后台生活

默认每 **5 分钟**决策一次，每日自主决策上限 **288 次**。上限是次数而非金额；不同供应商和输出长度会影响费用。手动聊天独立计数，不受自主上限限制。

- 手动场景活动和物品互动是本地确定性操作，不调用模型。
- 只有 AstrBot 运行、插件启用且自主生活打开时才推进。关闭页面不暂停，多个页面不会增加后台任务。
- 停机、停用和重载期间冻结进度，不补跑、不编造离线日记。
- 模型只提出一次固定活动或库存动作，后端验证后执行；没有任意坐标或移动家具的权限。
- 模型超时、无效 JSON、动作不匹配或世界版本过期，不会写成完成日志；插件层不自动重试。
- 暂停后已发出的请求可能仍由供应商计费，但过期建议不会改变已暂停的世界。供应商自行配置的重试可能产生额外请求。
- 饱腹、精力和心情不会导致角色死亡或不可逆损失，没有上线打卡惩罚。

模型需按提示返回 JSON，但不要求原生工具调用或多模态。收到的数据只有本角色设定、固定活动点、库存物品名称及描述、近期聊天、真实行为和长度受限的记忆摘要。
本插件不读取其他 AstrBot 会话，不保存 API 密钥。v0.3.1 可按独立授权开放 AstrBot 工具与 Skills；默认限制访问、白名单为空，详见 SKILLS-PREVIEW.md。

## 数据与存档

状态、聊天、记忆和个人图片保存在：

```text
data/plugin_data/astrbot_plugin_whale_home/
  home.sqlite3
  assets/
  backups/
```

不要公开这个目录。数据没有额外加密，遵循宿主文件权限；页面共用 AstrBot Dashboard 的登录权限，不另设多人账户。

设置中可导出版本 2 JSON 存档，也可导入版本 1 / 2。存档包含状态、最近最多 5000 条聊天、5000 条日记、300 条记忆及被引用的图片；**不导出模型选择、密钥或后台开关**。
恢复前自动备份，保留本机模型选择并暂停自主生活；本机调用计数及请求去重记录不因导入而重置。
非法版本、错误图片摘要、缺失图片及非法状态先拒绝，不覆盖当前存档。

JSON 存档上限 25 MB。自定义图片仅支持静态 PNG / JPEG / WebP，每张不超过 5 MB 或 1600 万像素，上传后去元信息、缩放并重新编码。
自定义角色图片建议无多余透明边缘且脚底对齐。再次分享包含个人图片或聊天的存档前，请自行确认隐私及素材权利。

## 开发和验证

Node.js 22.12 或更新版本；推荐通过 `uv sync` 安装后端开发依赖。

```shell
uv run pytest -q
uv run ruff check whale_home main.py tests tools
uv run python tools/prepare_scene_assets.py
cd frontend
npm ci
npm run build
npx playwright install chromium
npm test
```

首次测试需要安装 Playwright 浏览器；测试配置将缓存放在项目的 `.runtime/browsers`，可先设置 `PLAYWRIGHT_BROWSERS_PATH` 为该目录后执行安装命令。
Windows 可设置 `PLAYWRIGHT_CHANNEL=msedge` 使用已有 Edge 无头测试。
本地预览使用真实状态和规则，但模型是明确标注的、不联网的演示实现，数据与 AstrBot 隔离：

```shell
uv run python tools/dev_server.py --port 18761 --data-dir .local/preview-v020
```

访问 `http://127.0.0.1:18761`。只监听本机，不代表真实在线模型验收。

新增 `POST scene/interact`：提交 `spot_id`（`bookshelf/desk/window/bed`）、匹配的 `action`（`read/play/move/rest`）和原有 `request_id`、`expected_version`。状态快照增加 `scene`，角色用 `location` 和活动点 `last_path`；设置增加 `character_style`（`portrait/chibi`）。
模型动作使用 `{type, spot_id}` 或 `{type, target_id}`；库存字段为 `inventory`。旧 `layout` 接口明确拒绝自由布置。

运行 `python tools/package_plugin.py` 生成 v0.4.2 公开完整安装包、源码包与独立 `SHA256SUMS-v0.4.2.txt`。仅按白名单打包，不含虚拟环境、缓存、个人数据库、凭据或日志；发现同名不同内容的包会拒绝覆盖，可用 `--output artifacts/release-v042/staging` 指定新的工作区内暂存目录。源码包按显式白名单包含离线测试所需的参考素材、提示词、原图及无密钥的摘要审查记录/调用台账；不包含凭据、请求日志或个人存档。
当前功能验证范围见 `RELEASE-V042.md`，历史验证见 `RELEASE-V031.md`、`RELEASE-V030.md` 和 `VERIFICATION.md`。
